## 💼 Experience

### 🧠 AI Engineer Intern, OutMate *(Mar to Apr 2026)*
> AI-powered GTM assistant for sales teams. Next.js 14 · FastAPI · Celery · Redis · Supabase · Claude API · OpenRouter

Designed and shipped **12 production AI features** end to end.

<details>
<summary><b>🤖 Automation Agent</b></summary>
<br/>
Claude tool-use agent with 20+ JSON schema tool definitions. Navigation and filter injection run client-side (zero backend latency). Zustand <code>submitSignal</code> pattern for form auto-submit without prop-drilling, plus a filter undo stack for state rollback.
</details>

<details>
<summary><b>🎯 Orchestrator</b></summary>
<br/>
LLM planner generates an <code>ExecutionPlan</code>. Topological sort on <code>step.depends_on</code> resolves parallel groups, <code>asyncio.gather</code> runs them concurrently, and a merger LLM synthesises the outputs. Full audit log of plan, steps, credits and duration per run.
</details>

<details>
<summary><b>💬 Global Chatbot (RAG)</b></summary>
<br/>
RAG over 51KB of feature docs. Route-aware with a 19-route feature registry injected per request. Two-stage intent detection (keyword pre-filter, then LLM classifier at temp 0.0). A <code>_validate_links()</code> post-processor strips hallucinated URLs.
</details>

<details>
<summary><b>⚡ Lead Copilot Panel</b></summary>
<br/>
14 GTM AI actions (email drafting, objection handling, battle cards, compliance audit, intent scoring). Two-stage SSE streaming with 50ms token batching cut React re-renders from about 700 to about 15. Redis cache keyed by <code>action:prospect_id:sha256(prompt)[:8]</code>.
</details>

<details>
<summary><b>📧 Email Optimizer</b></summary>
<br/>
5-source parallel enrichment via <code>asyncio.gather</code> (Serper, Tavily, Explorium, LinkedIn, YouTube) with 15s per-source timeout isolation. Outputs a personalised email, Day 3/7/14 follow-ups and a reply probability score.
</details>

<details>
<summary><b>🔔 Real-time Notifications</b></summary>
<br/>
Redis pub-sub to SSE. Manual JWT validation on SSE endpoints (browser <code>EventSource</code> can't set auth headers), 25s heartbeat, and <code>grouped_count</code> dedup to prevent notification spam.
</details>

<details>
<summary><b>📅 Scheduling</b></summary>
<br/>
Celery Beat for a timezone-aware Daily Brief (±2 min window, idempotent <code>get_or_generate()</code>). Meeting Prep auto-triggers at T-30 via Google Calendar webhooks with a Redis dedup key (2hr TTL).
</details>
